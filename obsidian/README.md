# Brandon's Job Search Vault (Obsidian)

This folder is an **Obsidian vault**. To use it:

1. Open Obsidian → **Open folder as vault** → select this `obsidian/` folder
   (or copy its contents into your existing vault).
2. Start at **[[00 Job Search Dashboard]]** — that's your home base.

## How it's organized

- **[[00 Job Search Dashboard]]** — master list of every application, its status, and which resume/cover letter it uses. Start here.
- **Resumes/** — your resume variants (readable here, with links to the compiled files):
  - [[Sales Track Resume]] — enterprise/AE sales roles (Tiers 2 & 3)
  - [[NOW Job Resume]] — simple 1-page resume for fast, high-hourly "money now" jobs
  - [[Founder Track Resume]] — founder/executive/GM roles
- **Applications/** — one note per job. Each links to the resume + cover letter to use, the live posting, screening answers, and status.
- **Tiers/** — the three buckets:
  - [[Tier 1 - Now]] — money this week
  - [[Tier 2 - Good Pay]] — realistic, well-paid targets
  - [[Tier 3 - Long Shots]] — reach roles

## The links (Obsidian wikilinks)

`[[Note Name]]` is a clickable link between notes. Click any to jump. The dashboard
and tier notes link to every application; each application links back to the resume
and cover letter it uses, so you can always find "what do I send for this job" in one hop.

> here so this vault is self-contained even without LaTeX.
